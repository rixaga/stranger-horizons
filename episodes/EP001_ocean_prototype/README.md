# EP001 — Ocean Prototype

**Status:** prototype_planned

A 10-second technical and visual proof of concept, not a published episode.

## Goal
Validate Stranger Horizons' visual direction and Blender workflow.

## Planned sequence
- Opening: near-black water and subtle particles.
- Reveal: motivated volumetric light and depth gradient.
- Scale cue: distant seabed feature or silhouette, without implying a real undocumented creature.
- Camera: slow, stable forward movement.
- Ending: hold composition long enough to read.

## Outputs
- Editable .blend project
- Re-runnable Blender Python scripts
- Preview render at 1280×720 or 1920×1080, 30 FPS
- Render settings and software version notes
- Prototype evaluation

Do not create a complete episode in this prototype stage.
