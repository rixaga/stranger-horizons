# Start Here — Claude Code Workflow

Run these prompts one at a time. Do not skip stages or approval gates.

## Stage 1 — Understand the repository
Read CLAUDE.md, README.md, this file, and all relevant docs. Inspect the full repository and machine capabilities. Do not modify files yet. Summarize channel identity, audience, pillars, research standards, visual direction, pipeline, technical assumptions, existing assets, gaps, and risks. Create PROJECT_UNDERSTANDING.md. Stop and wait.

## Stage 2 — Analyze the supplied YouTube reference
Reference: https://youtu.be/GM1DIGlDVa0

Watch the entire video if genuinely accessible. Analyze timestamps, shots, camera movement, composition, lighting, color, atmosphere, animation, transitions, pacing, sound design, and plausible Blender techniques. Create REFERENCE_VIDEO_ANALYSIS.md and REFERENCE_SCENE_BREAKDOWN.md. Separate direct observations from interpretations. If playback is unavailable, request a local video file or timestamped screenshots. Never invent observations. Stop.

## Stage 3 — Adapt the reference
Using the verified analysis and channel bible, refine docs/VISUAL_STYLE_GUIDE.md. Adapt techniques, do not copy the video. Preserve Stranger Horizons' broad documentary identity. Define reusable camera, lighting, atmosphere, material, and environment presets. Stop for review.

## Stage 4 — Plan production implementation
Inspect the actual environment. Plan research, source verification, script, narration, storyboard JSON, Blender scene generation, rendering, audio, editing, subtitles, thumbnails, and QA. Identify automation and human approval gates. Create docs/PRODUCTION_IMPLEMENTATION_PLAN.md. Do not overengineer. Stop.

## Stage 5 — Build Blender prototype
Create a 10-second cinematic deep-ocean prototype, not a full episode. First inspect Blender, Python, FFmpeg, GPU, memory, and disk. Use preview settings. Build dark underwater environment, volumetric light, particles, readable seabed silhouette, and slow camera move. Save .blend and scripts under episodes/EP001_ocean_prototype/. Validate and render if possible. Report actual versions, settings, files, and outcome. Stop for approval.

## Stage 6 — Evaluate and iterate
Compare the actual preview against approved guide and verified reference notes. Evaluate composition, scale, lighting, atmosphere, realism, motion, noise, and readability. Create PROTOTYPE_EVALUATION.md, fix high-impact issues, and render a second preview. Stop.

## Stage 7 — Produce Episode 001
Only after explicit prototype approval: research and source-check topic, create claim-level dossier, draft and approve script, create storyboard, validate scenes, produce Blender shots, narration, sound, edit, subtitles, thumbnail, and QA. CGI must not be presented as authentic footage. Stop at major approval gates.

If the YouTube link cannot be played, request source media. Never infer its content from its URL.
