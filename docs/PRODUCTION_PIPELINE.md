# Production Pipeline

Research → claim audit → script → narration → storyboard → Blender scenes → render → sound/edit → subtitles/thumbnail → QA → publish.

## 1. Topic and research
Input: topic brief and audience. Output: source dossier, claim ledger, counter-evidence, narrative angle. Gate: key claims have adequate sources.

## 2. Script
Output: structured script with hook, context, investigation, alternatives, verdict, and source markers. Gate: editorial and factual approval.

## 3. Narration
Output: narration text, pronunciation notes, estimated duration, voice assets. Use authorized voices and licensed music.

## 4. Storyboard
Each scene records scene ID, duration, narration, visual intent, factual/reconstruction status, camera, environment, assets, lighting, effects, transition, sound notes, and source IDs.

## 5. Blender production
Build reusable environments/assets. Validate project, dependencies, camera, frame range, render settings, and output path. Preview before final render.

## 6. Audio and editing
Assemble narration, ambience, music, and effects with clear dialogue intelligibility. Respect licenses and avoid misleading sound design.

## 7. Packaging
Generate and proofread subtitles. Create accurate titles and thumbnails.

## 8. QA
Check factual claims, clipping, black frames, dropped frames, subtitle timing, render artifacts, aspect ratio, encoding, and file integrity.

## Approval gates
Research → script → storyboard → visual prototype → final cut.
